# GOON FX PRO V2 — Navigation + All-Market Digit Circles

Fixes:
- Navigation routes use a safe route resolver and section IDs.
- Manual Trader, Over/Under, Digits, Even/Odd, Rise/Fall, Higher/Lower, Touch/No Touch, Matches/Differs, Markets, History, Account, Settings and Bot Builder can be opened without relying on fragile inline routing.
- Digit circles are rendered in every trading/market section and share the same live tick sample.
- Clicking a circle selects that digit as the manual barrier where applicable.
- The circles are a statistical display of recent ticks, not a guaranteed predictor.
