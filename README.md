# GoonFx Trading App

GoonFx is the production Deriv trading dashboard for the `arnold956/goonfx` repository.

The application uses the Deriv WebSocket API for live market data, proposals, account information and authorized trade execution.

## Deployment

Production source of truth: `arnold956/goonfx` on the `main` branch.

The legacy `arnold956/goonfxg` repository is no longer used as a source for this project.
